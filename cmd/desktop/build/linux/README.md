# SQLWarden for Linux

The Debian package declares its GTK3 and WebKit2GTK 4.1 runtime dependencies. When using the tarball on Debian or Ubuntu, install them before starting SQLWarden:

```sh
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
```

Other distributions use different package names. See the Wails Linux runtime documentation for the current distribution-specific list:

https://wails.io/docs/guides/linux-distro-support/
