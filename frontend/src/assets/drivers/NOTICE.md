These SVGs are official logos of the database engines and platforms SQLWarden
supports, used unmodified to identify each connection type in the UI. Each logo is
a trademark of its respective owner — see `/NOTICE.md` at the repo root.

When adding a logo for a new engine:

- Use the vendor's current official asset (brand/press page or, where a vendor
  doesn't publish one, an unmodified copy already in wide FOSS use), not a
  redrawn or recolored copy.
- Don't combine it with other marks or add effects/taglines.
- Cockroach Labs, MariaDB Corporation, and PostgreSQL's project explicitly document
  reproduction rules (no recoloring, no rotation, standard forms only) — check the
  relevant vendor's trademark/brand page before swapping an asset.
